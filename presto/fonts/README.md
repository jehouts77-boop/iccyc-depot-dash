# Fonts

Smooth (PicoVector) fonts for the Presto screen, in Pimoroni's Alright Fonts
`.af` format. Copy the two `.af` files to the root of the Presto (`/`).

| File | Typeface | Used for | Licence |
|---|---|---|---|
| `BarlowCondensed-Medium.af` | Barlow Condensed Medium (Jeremy Tribby) | everything | SIL Open Font License 1.1 - `BarlowCondensed-OFL.txt` |
| `SpecialElite-Regular.af` | Special Elite (Astigmatic) | On This Day, the Fitzgerald screen | Apache License 2.0 - `SpecialElite-LICENSE.txt` |

Chosen by Jason 2026-10-07 from `renders\font_mockup_2026-10-07.png`.

Converted 2026-10-07 from the TTF files in github.com/google/fonts with
`afinate --quality medium` (github.com/Gadgetoid/alright-fonts, branch
`feature/16bit-afinate`, the one Pimoroni's picovector-fonts uses), characters:
printable ASCII (32-126) plus the degree sign.
